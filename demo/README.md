# Demo

This directory contains the BRZtracer showcase page (`index.html`) plus the
assets and tooling that produce it.

## Contents

| Path | Description |
| ---- | ----------- |
| `index.html` | Self-contained showcase page (no external dependencies; works offline) |
| `images/` | Source pixel-art PNGs |
| `output/` | SVGs generated by the `brztracer` release binary at the configured scales |
| `../scripts/build_demo.py` | Regenerates `output/` and `index.html` from `images/` |

Open `index.html` in any browser. Drag the divider in each card to compare the
original pixels against the traced vectors; use the scale buttons to switch
xBRZ factors.

## Regenerating

```bash
cargo build --release
python3 scripts/build_demo.py
```

The script runs the release binary on every image in `images/` at the scales
configured at the top of the script, collects stats (dimensions, path/loop
counts, file sizes), and rewrites `index.html` with that data embedded.
